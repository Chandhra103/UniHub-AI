# B. Chandhra Shekhar — Personal Portfolio

The complete 8-page personal portfolio (Home, About, Projects, Experience, Skills, My Thinking, Voice & Creativity, Contact).

This folder is self-contained and does not modify the UniHub-AI application in any way.

## Run

```sh
node server.mjs
```

Open http://localhost:3000 — or deploy this folder as a static site (its `public-style` root: `index.html`, `styles.css`, `app.js`, `assets/`).
